# 知问工作流程

任务码由用户在登录知问后生成，短期有效，并限定账号、任务和资料。每次工具调用均传入任务中的 task_code。先调用 get_account 核对网站账号；网站身份独立于 ChatGPT 身份。不要索要网站密码。缺少任务码或码已过期，请用户回网站重新生成；不要尝试其他账号或扩大权限。

## 教材和范围

先读取任务目标配置。出题首先调用 get_exam_draft，读取完整题型数量、难度比例、章节、材料 ID 和现有状态。通过工具读取网站保存的资料，不能假设另一台电脑存在教材文件，也不能依赖发布者的本地路径。教材正文只读已选章节；分页读取时遵守工具返回的数量上限。目录不足以支撑严谨命题时，先读取指定章节正文。扫描件缺乏可读正文时说明缺口，请用户上传可识别版本或完成识别，不能编造原文。

无教材且配置允许网络资料时，依据课程名和学习目标检索大学、官方文档或公开教材等权威来源，至少核实两个来源，保存来源及课程大纲后组卷。不要把搜索摘要当作教材全文，不应声称网络资料来自用户教材。目标和范围不足以确定课程时再澄清。

## 组卷和发布

严格执行草稿配置。将总题数按难度比例分配为整数；存在舍入余数时按最大余数分配，并同时核对各题型数量。不同题目应考查不同任务或推理过程，单纯替换数字、人物或符号不能算新题。计算题逐步复算，选项应有唯一正确答案（多选则明确完整正确集合），参考解答解释关键依据。

读取历史题目并调用 check_exam_similarity；同时检查本卷内部重复。超过配置阈值的题目改换情境、所需推理或知识组合后重写，重新检查。知识点相同不等于题目可重复。不得只换词以规避检查。发布前核对题型、数量、难度、章节覆盖、分值与答案。若校验失败，修复并复验；用 publish_exam 发布后再读取状态确认成功。不要覆盖已有作答的试卷，重试前先读草稿确认是否已发布。

## 复盘

读取指定 submission 和原始题目、作答，依据评分标准逐题解释。客观题遵守标准答案；主观题指出得分点、错误和改进。保存复盘后读取确认结果，不能把保存成功当作已批改全部题目。

## 安装检查

配置连接的是公开 MCP 传输入口，实际资料访问由短期任务码控制。安装插件后可能需要新建 Codex 对话才能发现工具。先用网站“连接验证”任务核对账号；仅安装成功不代表已经绑定网站身份。任务码不要提交到 GitHub 或放在公开截图中。
