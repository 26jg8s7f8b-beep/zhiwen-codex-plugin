# 知问 Codex 插件

用于知问网站的教材处理、严格组卷和主观题复盘。插件连接远程服务，教材保存在网站，不要求用户电脑具有相同的本地文件路径。

## 使用

1. 在知问网站注册或登录自己的账号；显示昵称可以重复，登录账号唯一。
2. 将本仓库作为 Codex 插件来源添加，在插件目录安装并启用“知问”。不同 Codex 版本的入口可能不同；安装后新建对话检查是否出现知问工具。
3. 在网站设置里生成“连接验证”任务，复制到已启用插件的 Codex 并发送。
4. 在网站上传教材、选择章节和出题配置，然后将生成的任务发送给 Codex。无需教材时填写课程名与学习目标，Codex 会先核实公开资料并保存来源。
5. Codex 发布后回网站刷新查看试卷。复盘同样由网站生成专用任务。

网站可以准备并打开 Codex 任务，实际发送由用户在 Codex 中完成。不是每台电脑都支持应用深链，网站应保留复制指令入口。

## 数据与权限

网站账号与 ChatGPT 账号独立。MCP 入口公开但资料接口必须使用网站生成的短期任务码，限定账号和任务；任务码过期需重新生成。退出网站会撤销该账号的任务码。不要把密码或任务码提交到仓库。

本仓库不包含教材、题库、作答、账号信息或服务器密钥。仅提供插件配置及工作流程。服务地址固定为知问站点；自行部署者需更改 mcp.json 中的 URL。

## 安装指令

把下面这段交给你的 Codex：

> 请从 https://github.com/26jg8s7f8b-beep/zhiwen-codex-plugin 安装知问插件。读取仓库的插件目录配置，将其添加为插件来源并安装启用 zhiwen。安装后告诉我是否需要新建对话或重启客户端。不要向仓库上传我的教材、答案、密码或任务码。

支持插件市场命令的 Codex 版本可用 `codex plugin marketplace add 26jg8s7f8b-beep/zhiwen-codex-plugin` 添加来源，随后在插件目录安装知问。此命令仅添加来源，不等于插件已安装。

## 发布校验

网站会校验题型数量、难度分配、选定章节和相似度。每道题需提供 difficulty（easy/medium/hard）；指定章节时，chapter 使用配置中的完整章节名。请先读取任务配置，不能通过改配置绕过校验。难度比例按最大余数法分配整数题数。

此插件需要能访问知问服务的网络环境、支持插件及远程 MCP 的 Codex 客户端。若客户端缺少相应功能，请更新客户端后再试；不能将单次 HTTP 测试视为所有电脑均安装成功。
